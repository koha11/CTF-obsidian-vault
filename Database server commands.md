### PostgreSQL
```
\c dbname           -- Kết nối đến database
\q                  -- Thoát psql
\l                  -- Liệt kê tất cả database
\conninfo           -- Xem thông tin kết nối hiện tại
\d                  -- Liệt kê tất cả bảng
\d tablename        -- Xem cấu trúc bảng
\dt                 -- Liệt kê bảng thường
\di                 -- Liệt kê index
\dv                 -- Liệt kê view
\du                 -- Liệt kê roles
\dn                 -- Liệt kê schema
\df                 -- Liệt kê hàm
\dv                 -- Liệt kê view
\dt *.*             -- Liệt kê bảng ở mọi schema
\h SELECT           -- Xem cú pháp SELECT
\?                  -- Trợ giúp tất cả lệnh meta
\set                -- Xem/đặt biến trong psql
```
